# QR Menu (PWA + Supabase + GitHub Pages)
1. supabase.com वर प्रोजेक्ट बनवा → SQL Editor मध्ये `supabase.sql` चालवा (आधी `your@email.com` बदला).
2. Authentication → Providers → Email → "Confirm email" बंद करा.
3. Project Settings → API मधून URL आणि anon key `config.js` मध्ये टाका.
4. GitHub वर सर्व फाइल्स अपलोड करा → Settings → Pages → Branch: main → Save.
5. उघडा: `https://<user>.github.io/<repo>/#admin` (खाते बनवा, लॉगिन, रेस्टॉरंट जोडा).
   ओनर: `#owner` | शेफ: `#chef` | वेटर: `#waiter` | ग्राहक: QR (`?r=demo&t=1`).
